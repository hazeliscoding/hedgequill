# Font sources

Static TTF files, copied unchanged from [google/fonts](https://github.com/google/fonts), in only the styles the screens use. Avalonia reads neither WOFF2 nor variable fonts. Both families are under the SIL Open Font License 1.1, and each folder holds its `OFL.txt`, which the app embeds with the font.
